# MoodWhisper 后端系统

📌 项目简介：

MoodWhisper 是一个情绪可视化平台，用户通过与硬件交互，产生语音及情绪数据，后端负责存储并提供情绪趋势分析、社区展示及个人主页展示功能。

🚀 技术栈： 
- 语言： Go 1.21+ 
- 框架： Gin（Web 框架）、GORM（ORM） 
- 数据库： PostgreSQL 
- 认证机制： JWT 
- 静态文件支持： 前后端分离，兼容 HTML 模板或 React 等前端框架

---

📂 模块功能说明：

✅ 用户模块（/user）

| 接口	               | 方法	   | 功能             |
|-------------------|-------|----------------|
| /user/register    | 	POST | 	用户注册          |
| /user/login       | 	POST | 	用户登录，返回 JWT   |
| /log/user/profile | 	GET  | 	获取用户资料（含日记数量） |
| /log/user/profile | 	PUT  | 	修改签名 / 头像     |


✅ 情绪上传模块（/api/emotion）

| 接口                  | 	方法   | 	功能                   |
|---------------------|-------|-----------------------|
| /api/emotion/upload | 	POST | 	上传情绪互动记录（音频、情绪值、时间等） |


✅ 情绪趋势分析模块（/api/emotions）

| 接口                 | 	方法  | 	功能                               |
|--------------------|------|-----------------------------------|
| /api/emotion-years | 	GET | 	获取有记录的年份                         |
| /api/emotions      | 	GET | 	根据 year/month/week/day 返回趋势图所需数据 |


✅ 日志模块（/log）

| 接口                        | 	方法   | 	功能                             |
|---------------------------|-------|---------------------------------|
| /log/create               | 	POST | 	创建一条互动日志                       |
| /log/list                 | 	GET  | 	获取所有日志（用户使用）                   |
| /log/user/lastInteraction | 	GET  | 	获取用户最近一次互动数据（展示在 dashboard 顶部） |


✅ 社区模块（/log/community）

| 接口                   | 	方法   | 	功能                 |
|----------------------|-------|---------------------|
| /log/community/posts | 	GET  | 	获取所有社区日志（展示交互过程内容） |
| /log/community/post  | 	POST | 	（保留）用户发帖入口，现由硬件端代替 |

🧪 本地开发调试

环境依赖： 
- 安装 Go 和 PostgreSQL 
- 运行 PostgreSQL 并配置 .env：

```text
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=yourpassword
DB_NAME=emotion_app
JWT_SECRET=your_jwt_secret
```

运行项目：
```bash
go mod tidy        # 安装依赖
go run main.go     # 启动服务
```

服务默认运行在 http://localhost:8080

🔒 鉴权机制：
•	用户注册登录后获得 JWT Token，前端需在后续请求头中添加：

`Authorization: Bearer <token>`

📁 数据库说明：

| 表名	                  | 功能                        |
|----------------------|---------------------------|
| users	               | 用户信息（用户名、邮箱、头像、签名等）       |
| emotion_interactions | 	每一次情绪识别记录（音频链接、情绪标签、时间戳） |
| emotion_logs	        | 日志记录（用户互动文字、时间戳、AI 建议）    |
| community_posts	     | 用于展示在社区的问答日志记录            |
